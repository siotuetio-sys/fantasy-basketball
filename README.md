# Perfect Draft Hoops

**Live:** https://siotuetio-sys.github.io/fantasy-basketball/

A fantasy basketball assistant for a 10-team H2H points league, in the same paper-and-ink style as [fantasy-baseball](https://github.com/siotuetio-sys/fantasy-baseball), with a leaf-green accent.

Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Branch `main`, folder `/ (root)`) and visit `https://siotuetio-sys.github.io/fantasy-basketball/`.

- **Overview**: tonight's lineup advice, hot / rising / cooling players, r/fantasybball hot threads, most-talked-about players, ESPN headlines
- **Schedule**: tonight's games with box scores scored in FP, games per team this week, standings
- **Matchup**: H2H points projection and win probability, 10-team league table, scoring rules (Yahoo / ESPN / Sleeper presets or custom)
- **Players**: game log, averages, FP trend, side-by-side comparison
- **Waiver wire**: last 7 / 14 / 30 days from box scores, rest-of-week value, "likely FA" flag for a 10-team league
- **Injuries**: ESPN injury report, translated to Chinese
- **Roster**: roster, watchlist, games remaining this week, share link

Data comes from ESPN's public JSON (site.api.espn.com) and Reddit. Your roster and settings are stored only in your browser's localStorage.
